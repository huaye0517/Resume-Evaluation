简历评估系统 - 快速上手指南
======================================

【前提】电脑需安装 Python 3.8 或更高版本
  下载: https://www.python.org/downloads/
  安装时务必勾选 "Add Python.exe to PATH"

【三步开始使用】
  1. 配置 API 密钥（见 "请先阅读-配置说明.txt"）
  2. 双击 start.bat 启动（首次会自动安装依赖，约 1-3 分钟）
  3. 浏览器打开 http://127.0.0.1:5000 开始使用

【遇到问题】
  - 双击 "环境检查.bat" 自动诊断
  - 详细说明见 "部署说明-给同事.md"
