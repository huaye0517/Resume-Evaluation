# AI 简历 JD 评估工具

一个本地运行的网页工具：上传/粘贴岗位 JD 和多份简历（PDF/Word），调用 DeepSeek 大模型逐份评估候选人是否适合面试邀约，给出结论、匹配度评分、亮点与风险点、建议面试问题，并支持一键导出 Excel 汇总。

适用岗位示例：抖音内容营销主管/经理、渠道分销专员、抖音内容素材主管、招聘主管、电商总账会计等。

## 功能特性

- JD 支持上传文件（PDF/Word）或直接粘贴文本
- 一次上传多份简历，批量逐个评估
- 智能 OCR 兜底：设计类排版 / 图片型 PDF（中文常因嵌入字体无法直接提取）会自动转 OCR 识别中文内容
- 结构化结果：结论（适合/待定/不适合）、0-100 匹配度评分、分项评分、亮点、风险点、建议面试问题
- 结果按匹配度自动排序，点击展开查看详情
- 一键导出 Excel 汇总表
- 单份解析或调用失败不影响整批，错误会单独标注

## 环境要求

- Python 3.9+

## 安装

```bash
pip install -r requirements.txt
```

## 配置

复制 `.env.example` 为 `.env`，填入你的 DeepSeek API Key：

```bash
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

## 运行

```bash
python app.py
```

启动后在浏览器打开 `http://127.0.0.1:5000` 即可使用。

## 使用步骤

1. 在「岗位 JD」区域粘贴 JD 文本，或上传 JD 文件（PDF/Word）。
2. 在「简历」区域选择一份或多份简历文件（PDF/Word）。
3. 点击「开始评估」，等待模型逐份分析。
4. 查看结果汇总表，点击某一行展开查看详细理由和面试问题。
5. 点击「导出 Excel」下载本次评估汇总。

## 说明

- 设计类排版 / 图片型 PDF（中文以图片或无 Unicode 映射字体渲染）会自动走 OCR 识别；首次触发 OCR 时需加载模型，耗时略长（约十几秒），之后会变快。
- 极少数清晰度过低的扫描件可能 OCR 效果不佳，建议尽量使用清晰、可复制文本的简历。
- 评估结果由大模型生成，仅供初筛参考，请结合人工判断。
